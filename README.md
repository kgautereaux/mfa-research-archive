# Vocal Pedagogy Research Archive

Published at [research.kaylagautereaux.com](https://research.kaylagautereaux.com).

This repository exists to host the rendered site, which lives on the `gh-pages`
branch. It holds no source and no data by design.

Source files are kept in a private repository. Research data, participant files and
exploration notebooks are never published here: the archive shows rendered findings
and interactive figures, and nothing that would let a reader reconstruct a dataset.

Maintained by Kayla Gautereaux, Boston Conservatory at Berklee.
